# AI Engineering Knowledge Base

This knowledge base records Telemetry's current understanding of AI/LLM fundamentals, prompts, instructions, agents and agent roles, task decomposition, context, tools, permissions, workflows, orchestration, multi-agent systems, and AI factories. It is practical software-engineering guidance that can evolve as we learn.

## Learning progression

```text
Prompt
  ↓
Instruction
  ↓
Agent
  ↓
Workflow
  ↓
Multi-Agent System
  ↓
AI Factory
```

The goal is not to build neural networks or become an ML researcher. The goal is to understand how to design, integrate, orchestrate, secure, evaluate, and operate AI-powered software systems.

Telemetry is our practical AI Engineering sandbox. We are moving gradually from human orchestration of AI agents, toward software-assisted orchestration, and potentially toward an AI Factory. The factory is a future concept, not an implemented Telemetry capability.

## How to read these notes

- **Current** describes practices or understanding we already use.
- **Conceptual** explains a model useful for reasoning and design.
- **Future** describes possibilities that are not implemented.
